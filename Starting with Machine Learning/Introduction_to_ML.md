# MACHINE LEARNING
ML is a part of computer science where we teach computers to *"learn from data"*, find patterns & make decision or predictions

## Types of ML
- Supervised Learning          --> Labelled Data
    1. Classificatiion Problems (data is classes or categories)
        - spam/not spam
        - cats/dogs/rabbit
        - grade (A,B,C,D)
    2. Regression Problems (predict continuous value)
        - aqi
        - stock price
        - marks / score
          
- Unsupervised Learning        --> Unlabelled Data
    1. Clustering Problems

- Reinforcement Learning       --> Goal Oriented Learning
    1. Mix of SL and USL



**"Labelled Data"** is raw data (such as images, text or audio) that has been paired with a meaningful tag, label, or annotation that informs a machine learning model about the desired outcome
